Cómo leer el mapa

Niveles de alerta

verde Impacto menor, no se espera que requiera asistencia internacional.

naranja Impacto medio, podría requerir cierta asistencia internacional.

rojo Impacto alto, probablemente requiera una respuesta internacional importante.

Tipos de evento

Uso

  • Los botones de la barra superior filtran por tipo y por nivel — clic para activar o desactivar.
  • Clic en un marcador abre el detalle: país, fechas, severidad, población estimada (solo disponible para terremotos) y enlace al informe oficial de GDACS.
  • El mapa se actualiza solo cada 5 minutos.

Datos

De GDACS (ONU + Comisión Europea). La API limita cada consulta a 100 eventos, así que en días de mucha actividad alguno puede quedar fuera.
